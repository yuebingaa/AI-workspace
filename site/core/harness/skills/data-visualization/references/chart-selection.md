# 图表选择与 QA

## 选择

| 数据关系 | 首选 | 使用条件 |
| --- | --- | --- |
| 时间或有序趋势 | 折线图 | 时间顺序必须真实；数据点过少时改用指标卡或柱状图 |
| 强调连续量级 | 面积图 | 面积填充确实能帮助理解量级，不用于无意义的离散分类 |
| 分类比较、排名 | 柱状图 | 无业务顺序时按值排序；长标签交由组件竖排和横向滚动 |
| 少量分类组成 | 饼图 | 仅非负值；分类宜少；必须保留分母与真实数值 |
| 少量分类组成且强调总量 | 环形图 | 与饼图条件相同，中心可显示总计或百分比 |

## 生成前检查

- 指标字段和分组字段都存在，并允许当前聚合。
- 日期、班次、线体和视图筛选来自服务端数据上下文。
- 负值不会进入饼图或环形图。
- 标题说明对象，副标题说明范围、班次或单位。
- Top N 不掩盖用户要求保留的重要类别。

## 渲染后检查

- 图形没有越过卡片，窄屏仍能访问全部分类。
- 长文字不重叠；类别多时柱位变紧并出现内部横向滚动。
- 单系列不显示多余图例，多系列才使用可区分的颜色与图例。
- 颜色不是唯一信息通道；数据仍可通过标签、提示框或隐藏数据说明访问。
- 页面修改保持在 ChangeSet 预览中，确认前正式 AppSpec 不变。
