# EDS 异常分析

先识别用户问题所需的数据层级，再使用当前 Harness 已开放的最小工具取得证据并给出结论。

## 判断层级

- 报告/班次：输入行数、命中数、命中率、总异常次数和总异常分钟。
- 线体汇总：比较各线体的次数和分钟，不需要线体×异常分类交叉明细。
- 全局异常分类：比较各异常类型的次数和分钟，不需要指定线体明细。
- 单条线体异常分类：只有明确指定某条线体时才需要线体×异常分类交叉明细。
- 原始记录：只有用户明确问原始行、单元格或未进入派生汇总的字段时才读取工作簿。

## 分析规则

1. 区分“异常次数多”和“累计时间长”，两者可能对应不同优先项。
2. 跨班或跨日期比较时，同时给出绝对差值和相对变化；分母为零时只报告绝对变化。
3. 命中率使用命中记录÷输入行数，不把异常次数误称为命中行数。
4. 结论引用工具返回的班次、线体、异常分类和数值；没有证据时不猜测根因。
5. 建议要指向可执行对象，例如优先排查的线体、异常类型和复核顺序。

字段、视图和工具边界需要确认时，读取 [references/eds-data-model.md](references/eds-data-model.md)。

## 边界

- 派生汇总足以回答汇总排名时，不要求重新读取原始数据。
- 不向用户暴露内部参数名、Schema 字段名或工具缺失占位符。
- 页面修改仍必须使用 Preview 工具并等待确认。
