# 本地项目与 Data Browser

实现状态：2026-09-13 第一版本地模式已在开发站 `http://127.0.0.1:3001` 完成浏览器验收；未自动发布到稳定站或重新打包便携版。

## 使用方式

1. 左侧点击 **Data Browser**（收起侧栏时也有数据浏览器按钮）。
2. 在“项目文件夹”中新建空白项目，或输入已有 AgentCanvas 项目的绝对路径打开。新建时路径留空，使用用户“文档 / AgentCanvas Projects”下的新目录。
3. 在该项目中导入 CSV / XLSX。选择的工作表成为独立数据表，原始文件另行保留；相同 XLSX 的多个工作表关联同一原件。
4. 数据表可预览字段和记录、供 Notebook 使用，或加入 AI 上下文。语义模型沿用现有创建、选择、编辑、删除界面，并随项目保存。
5. Notebook 的“生成看板预览”会把结果快照保存为项目结果表；正式看板仍需确认 ChangeSet，不会自动应用。
6. 等待顶部显示“已保存到本地项目”再关闭。重新打开项目可恢复定义和数据。切换回临时工作区不会清除原有浏览器工作区。

第一版输入文件夹路径，不提供操作系统文件夹选择器；不能把已有的任意非空文件夹直接当作项目。先创建空白项目，再导入文件。文件访问发生在运行网站的本机服务端，不是远程网页任意扫描访问者电脑。

## 文件夹结构

```text
我的项目/
  agentcanvas.project.json   项目清单、稳定 ID、原件关联、工作台定义与保存版本
  files/
    file-<UUID>.xlsx         原始文件（也可以是 CSV）
  tables/
    table-<UUID>.json        有类型的字段、数据行、数据质量和访问策略
```

清单中的文件位置为相对路径。数据表重命名不改变 ID。工作台定义包括 Notebook DAG、DataRecipe、语义模型及选择、AppSpec、ChangeSet 历史、最近聊天和任务记录；不等于保存整个服务端长期会话库。原始 XLSX 在 Data Browser 中可下载，刷新后不会自动恢复旧侧栏的浏览器 File 对象。

Notebook 单元的临时运行缓存不在项目清单中：重新打开后需重跑；显式生成的结果快照才是持久结果。结果仍遵守现有行数、字段、超时和敏感数据处理限制。尚未提供项目库独立的 SQL/Python 编辑器、数据库文件管理器或多人协作。

## 保存、冲突和恢复

- 数据文件为唯一名称、不覆盖的快照；清单采用有大小上限的原子写入、写入锁及内容比较。
- 工作台定义按 `stateRevision` 乐观并发检查。同项目多窗口写入发生冲突时暂停自动保存，不以最后一个窗口强行覆盖。关闭面板后先用顶部“备份”导出未保存定义，再在 Data Browser 中明确选择放弃未保存修改、重新打开磁盘版本。
- 当前窗口存在未确认的看板预览时，切换/退出项目会先询问是否放弃预览；不会把预览自动写成正式看板。数据目录也会保护该窗口正在预览引用的数据。
- 顶部 JSON “备份”只含工作台定义，不包含全部原件和数据行。完整备份应等待保存完成，再复制整个项目文件夹；不要在正在导入/保存时复制。
- 项目移动或复制后，使用新路径“打开已有项目”；不要只复制清单。另一台电脑仍需要可用的 AgentCanvas 本机程序，项目文件夹不是运行程序。
- 删除数据表会移入回收站，保留文件和 ID，可恢复。Notebook、语义模型、正式看板、可撤销历史或处理配方仍有引用时拒绝删除；第一版不提供永久清空或自动清理。
- 写入中断极少数情况下可能留下未登记的快照文件；不会主动删除它们。不要自行编辑清单或清理看起来重复的文件。

## 容量和数据边界

每项目最多 50 张表（含回收站）、100 份原件；原件不超过 10 MiB、单张有类型数据快照 32 MiB、登记数据总量 512 MiB、清单 8 MiB。已有 CSV、Notebook 和备份大小上限仍分别生效。适合本地小型分析项目，不是大数据存储系统。

项目数据不受临时数据的 30 分钟 TTL 影响。未打开项目时仍使用原来的临时仓库和过期规则。临时数据不能仅靠设置 `storageMode` 绕过过期限制。

仅本机回环地址与同源页面可使用项目 API。请求使用服务端登记的随机项目句柄，数据、Notebook、Harness 和会话都按项目范围选择；无句柄的请求走临时模式。不支持 UNC、磁盘根目录、用户主目录、符号链接或目录联接，读取文件会检查类型、大小和 SHA-256。

这是本地单用户模式，没有实现登录、多用户文件权限或加密。可信本机进程仍可访问用户拥有的文件；同源安全检查不是操作系统安全沙箱。模型 API Key、数据库凭据及运行环境配置不写入项目清单，仍由服务端私有运行目录管理；导入的文件和聊天文本本身可能包含敏感信息，项目文件夹应视为私有，不能直接提交 Git 或公开分享。

`local-projects.json` 仅在 `STUDIO_LOCAL_STATE_DIR` 中登记最近项目路径与句柄；目录索引最多 100 个。通过 `npm run site:*` 管理的本机站点已配置该目录。目录登记文件不是项目正文，搬家时无需复制它；在另一台机器重新打开项目即可登记。

## 验证

新增单元测试覆盖重开与目录复制、数据完整性、访问策略、引用保护、回收站和版本冲突；浏览器验收脚本与本轮实测结果见 [Agent 架构维护入口](architecture/agent-architecture.md)。测试数据均为合成数据，不读取内部 Excel 或真实数据库。
