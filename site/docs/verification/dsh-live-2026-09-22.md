### 从失败中确认的最小修补

静态追踪及离线矩阵确认：注册器原本抛出带字段 / code 的 `HarnessToolArgumentsError`，broker 把它改成通用 422，SDK 插件再丢弃响应正文，模型只能看到状态码。这是已确认的错误反馈损失，**不是已确认的本次 cellSearch 根因**。

本批仅修补这条反馈：`tool-broker.ts` 只对当前工具的可信参数异常、且再次授权通过时返回严格 `invalid_tool_arguments` DTO；`runtime/dsh/tool-diagnostics.mjs` 限制为 Schema 自有属性 / 数组路径和白名单 code，最多六项，动态字典键 / 参数值 / 原始错误不透出；`controlled-plugin.mjs` 再验证 DTO 后保留这些诊断，仍抛失败而非伪装成功。业务校验、授权、未知异常保持通用错误，不放宽 Schema、不加工具次数、不自动 fallback。

另增加 `verify-dsh-adventureworks.test.mjs` 九项离线候选机制测试；空 Notebook 默认检索成功，非法参数 / 无锚点遍历 / 并发占用按原规则拒绝。验收脚本今后只记录脱敏工具失败分类 / 字段 / code，不记录完整参数；此修改不能回填已结束的那次真实调用。

费用按官方峰时缓存未命中单价保守估算约 **US$0.0069891**；忽略缓存 / 非峰时优惠，不是账户实际扣款账单。不因第一次失败自动重复消费，也不增加网站正常模型额度。

## 实际修改与模块边界

- `runtime/dsh/installation.mjs`：受管树选择、严格指针、版本 / ZIP 补丁 / manifest+lock 身份验证；不负责 Agent 规划或业务数据。
- `scripts/setup-dsh-runtime.mjs`：独立 staging 安装、验证后原子选择、复用与显式回退。仅隔离 SDK 的 manifest / lock 改动，不重生成网站主锁文件。
- `runtime/dsh/driver.mjs` / `core/agent-engines/server/dsh-driver.ts`：一次任务捕获一个安装；固定开发载体修订，避免热更新继续调用硬编码旧路径。
- `scripts/test-database/verify-dsh-adventureworks.mjs`：归属 / 权限预检、真实业务端口与参考 SQL 比较；fixture 默认不调用模型，live 仅接受本机验收网关。
- `scripts/dsh-live-model-gateway.mjs` / `verify-dsh-live.mjs`：测试级费用保护、临时令牌、完整 usage 统计、显式一次任务。不是产品模型适配层，也不改变产品执行配额。
- `scripts/verify-dsh-live-settings.mjs`：只读设置回归；空连接目录是明确脱敏替身，真实引擎状态不替身。
- `scripts/check-agent-architecture.mjs` / 对应测试：将新的安装选择模块纳入指纹保护；Agent 唯一架构和 Runtime README 同步。
- `core/agent-engines/server/tool-broker.ts`、`runtime/dsh/controlled-plugin.mjs` / `tool-diagnostics.mjs`：在业务工具和 SDK 之间保留严格、脱敏的参数纠错反馈，不改变业务参数含义。

数据库仍由现有 `core/connections` 持有连接 / 凭据 / 只读执行，Notebook 持有 DAG / 运算 / 表图结果和草稿证据；DSH 不获得 PostgreSQL SDK / 密码，不直接写正式项目。模型 / 执行器替换入口仍为 `DshDriver` 和既有引擎选择；本轮只把 SDK 安装可替换入口独立出来，不承诺任意供应商零修改替换。
