模型、数据库和 Agent 适配边界沿用前两批实现，本批没有增加一套替代执行器。以后修改当前 Dataset 的统计定义主要落在纯函数及测试；原件语义仍由原件引擎负责，两者不能机械合并。统计规则是版本化工具证据，不保证所有模型一定遵守。

## 固定样例与独立核对

固定 CSV 为 9 条数据记录、3 个声明字段。`1` / `01` / `1.0` 在原导入流程转为数字 1；空字符串 / 纯空白转 null；`NULL` / `false` 在混合字符串列保持文字。预期直接写在独立测试 fixture 中，不通过产品统计函数计算期望值。

| 指标 | 固定期望 | 实际 Dataset / SQL / Python |
| --- | ---: | --- |
| 行 / 字段 / 单元格 | 9 / 3 / 27 | 三者一致 |
| null / 缺失单元格 | 6 | 三者一致 |
| 全部声明字段为空的行 | 1 | 三者一致 |
| 不含第一次的重复行 | 4 | 三者一致 |

真实 SQL 与 Python 分别直接依赖同一个 Data 单元，不互相使用计算结果。刷新后重新执行仍一致，保存值 / 字段元数据 / 单元定义也核对不变。保留原评分 81%、原类型冲突和异常提示，没有将评分当正确性证明。
