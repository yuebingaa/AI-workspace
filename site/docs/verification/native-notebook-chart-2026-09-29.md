# 官方 Graphic Walker 与 DSH 图表配置（B4）

日期：2026-09-29。主流程源码 / 3001 已接入；官方 Tooltip 补丁已安装、进入构建，但运行中的开发站仍缓存旧依赖，待用户允许重启 3001 后完成该项浏览器验收。未发布 3000。

## 实现

- Notebook 直接复用固定 GW 0.5.2 `GraphicWalker` 编辑组件；`native-adapter.ts` 将公开 IChart 无损映射到既有 ChartConfig，不能保存的功能明确报错，不静默删减。
- `chart-authoring.ts` 为 DSH 和手动保存共用的构建器；editNotebookCells 新 `charts` 入口派生重复宿主字段，保留原 DAG、权限、版本、试运行与提交流程。
- 没有升级 GW 或改持久化版本。初试外部 MobX reaction 无法观察内置 store，已撤回直接依赖；以固定版本实际发出的编辑事件和公开 store 导出回调，回归覆盖实例隔离、卸载和撤销。ShadowDom 的 store 异步挂载需单独接线，不能只读一次父 effect。
- 官方 multiEncodeEditor 存在后续 Tooltip 操作始终索引 0 的缺陷，已通过 pnpm 可追踪补丁修正源码及网站消费的 ESM，不直接编辑 node_modules。未用的 UMD 未修改；见 [补丁维护说明](../../patches/README.md)。pnpm 安装 / patch-commit 成功，保留既有 arrow2csv shim 和弃用警告；不宣称完全离线安装（环境仍做联网供应链校验）。
- 旧多指标、饼环仍兼容；独立 /charts 简洁编辑器不在本批替换范围。
