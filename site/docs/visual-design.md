## 配色与布局

| 用途 | 颜色 / 约定 |
| --- | --- |
| 页面底色 | `#F7F6F3`，略暖的浅灰 |
| 内容表面 | `#FDFCFB`，接近白色 |
| 次级表面 | `#EFEDE9`，浅灰层次 |
| 主文字 / 主按钮 | `#20201E`，炭黑；主按钮白字 |
| 次级文字 | `#65625E` |
| 辅助文字 | `#767574` |
| 普通边框 | `#D7D6D5` |
| 强调边框 | `#B4B3B2` |
| 圆角 | 按钮与菜单以 3–5 px 为主，弹窗以 6–8 px 为主 |
| 间距 | 导航紧凑，内容区域留白；通过细边框和对齐建立层次 |
| 装饰 | 原生 SVG 灰度线条插画；主工作区使用纯净暖白表面，移除背景点阵 |
| 字体 | 系统无衬线字体，中文优先 Noto Sans SC / 苹方 / 微软雅黑回退；不新增远程字体依赖 |

全站配色入口为 [`app/studio-theme.css`](../app/studio-theme.css)，由 `app/layout.tsx` 在功能样式后载入。功能 CSS 直接引用 `--studio-*` 变量，不能只依赖首页的覆盖规则。新增界面、CSS Module、挂在 body 下的弹窗及编辑器浮层都须接入同一色板；避免重新引入成片绿色、紫色、彩色渐变或过重阴影。Puck 使用官方 root 主题变量，预览 iframe 同步宿主样式；数据图表的显式系列颜色保持独立。

成功、警告、错误仍可使用有语义的状态色，并同时保留文字说明。不能用全局灰度滤镜处理网站，以免改变用户上传图片、图表中的业务颜色或状态辨识。

工作台布局入口为 [`app/studio-layout.css`](../app/studio-layout.css)，在主题后载入，以 `.compact-studio` 限定主站布局，避免改变独立可视化测试页或用户图表的布局。导航高 56 px，内容区使用剩余动态视口高度；备案页脚存在时额外预留 28 px。

Notebook 代码单元的补充样式为 [`app/notebook-cells.css`](../app/notebook-cells.css)，在布局样式后载入并限定 `.compact-studio`。代码使用系统等宽字体、灰色行号与轻量语法区分，沿用暖白表面；审阅中的淡绿 / 淡红只表示新增 / 移除，并同时显示加减符号与文字。

## 当前页面规则

- 任务历史的模型用量：未设应用层配额时显示“实际消耗 / 不设本地限额”，不渲染该项额度进度条；旧任务仍显示原数字额度和比例。执行时间与超时卡片保留，不改变弹窗布局与灰度样式。2026-09-16 在 3001 隔离浏览器用合成 SSE 验证新旧回执、用量、保存刷新与桌面显示，无真实模型调用；[报告](../.runtime/harness-model-quotas-2026-09-16/browser-final/report.json)。验收时发现 390px 仍使用 310px 侧栏，新旧详情均被挤到 54px，手机布局未通过且本轮未修改 CSS。稳定站未发布。
- Notebook Python 单元沿用浅色代码卡片、等宽代码与行号，工具栏增加 Python 入口；编辑器提供上游 DataFrame 勾选、原始文件名称和输出表名。保存后显示当前版本结果，stdout / stderr 以“Python 输出与诊断”折叠，失败用文字说明并阻止下游使用旧结果。代码、表格和现有灰度图表保持同一文档样式，不新增独立内核面板。2026-09-16 已完成真实 Python → SQL → 图表、报错修复 / 刷新和 1440 / 390 px 浏览器验收，5 组检查通过，页面异常与模型调用均为 0；[证据](../.runtime/python-runtime-2026-09-16/browser-1789527246929/report.json)。仅开发站生效，稳定站未发布。
- 文件删除确认：文件侧栏与 Data Browser 原件分类统一使用居中的站内弹窗，宽度上限 560 px；暖白卡片、细边框、轻阴影与浅色半透明遮罩。标题“删除文件”，文件名用浅灰底突出并自动换行，说明实际回收站 / 会话原件规则；右下角为“取消”与浅红描边“删除”。默认聚焦取消，支持 Tab 循环、Esc / 遮罩取消及关闭后焦点返回；提交期间显示“正在删除…”并禁用重复操作，失败在弹窗内说明原因并提供重试。
- 文件删除：原始文件行的下载与更多按钮之间常显细线垃圾桶，使用克制的红色表示删除；保留文件名截断、完整名称提示与键盘操作。点击确认后项目原件移入回收站，已导入数据及 Notebook 保留；文件栏底部提供回收站入口，Data Browser 可以恢复文件。临时会话移除内存原件，重新使用完整原件需再次导入；成功说明、错误重试和运行中 / 查看者禁用状态均有文字或可访问标签。布局保持暖白与浅灰，不另开常驻工具区。
- 顶部：单行 56 px 导航，左侧为工作区菜单、品牌和当前界面，中间为三种工作模式，右侧为必要操作与真实保存状态。首访默认 AI 工作台，已有模式偏好继续恢复。
- 左上角菜单：点击后浮出新建界面、导入、功能搜索、工具、最近界面，以及可展开的“设置与备份”。搜索支持中文名称与 Data Browser、Files、SQL 等关键词；支持自动聚焦、方向键、Escape 和外部点击关闭。
- 模式导航：AI 工作台、Notebook、看板使用独立线条图标，当前模式用浅灰底和深色文字；保留方向键、Home / End 切换。
- AI 工作台：暖白背景、居中的灰度插画与轻量标题，三个小型建议按钮；共享输入框在底部，保留附件与上下文入口。建议只填入草稿；模式切换、AI 侧栏收放不重建聊天或输入区。
- 工具栏：Notebook 和看板左侧为 52 px 窄栏，包含数据浏览器、数据库连接、原始文件、语义模型、工作界面与数据、任务历史和导入；悬停或键盘聚焦显示名称。AI 首页默认隐藏工具栏，从菜单进入所需面板。
- 原始文件：点击文件图标或左上角菜单后，在工具栏右侧展开 286 px 文件面板，图标使用浅灰选中态。顶部为标题 / 收起按钮与虚线上传区，中部为数量、排序、搜索、紧凑文件行；文件名截断并可查看全名，尺寸 / 来源 / 日期分行，下载、删除和更多操作保持可见。点击文件行可展开关联数据及工作簿入口；下方连接和项目管理均使用真实入口。Notebook 保留在右侧，面板独立滚动，通过原关闭按钮收起。只显示实际可用的原件下载，临时原件丢失时标为已导入数据。样式入口为 [`app/files-panel.css`](../app/files-panel.css)，在已有主题 / 布局后载入。
- AI 侧栏：右侧保留独立提问和执行过程，可通过右上角“AI 助手”收放，仍可拖动调整宽度。无对话时使用简洁欢迎区，有任务、错误、结果或待确认变更时展示原有内容。
- 项目会话：AI 工作台与右侧助手顶部使用会话标题 / 下拉箭头，右侧“＋”新建。下拉为暖白、细边框和轻阴影，显示当前项目及其会话，当前项使用浅灰底与勾选；标题过长省略，完整名称可通过提示查看，长列表独立滚动。会话标题取首条消息，切换恢复该会话的聊天与文字草稿，刷新后保留选择；项目切换不展示其他项目会话。支持方向键、Home / End、Enter、Esc 与外部点击；任务执行、预览确认或编辑期间禁用切换并给出原因。样式入口为 `app/conversations.css`。
- 聊天内容：不显示“对话上下文 / 已保留几轮 / 清除上下文”工具栏。清除操作位于左上角菜单的“设置与备份”，也可搜索“清除上下文”；只清除当前选中会话，运行中或没有历史对话时禁用。会话下拉用于新建 / 切换，不恢复原计数工具栏。
- 看板：重新设计阶段使用纯暖白空白画布，不显示欢迎说明、插画、导入卡片或空白边框；导入 / 选择数据源不会自动附加“表格工作区”。顶部编辑 / 预览和左侧工具栏保留，数据仍可从文件面板、详情和 Notebook 使用。助手处理结果仅在已有菜单中明确选择后显示，离开后再次进入看板回到正常画布。已手动添加或确认的看板组件仍按定义呈现，不删除源数据、Notebook 或历史；空白画布填满桌面可用区域。
- Notebook：文档式大标题支持重命名，下方“添加分析说明”创建说明步骤；保存细节和连接目录默认折叠。空白页居中排列分析问题、上传 / 数据浏览器 / 数据库连接三个真实入口及已有数据快捷项，下方用图标工具栏集中八类分析单元。问题与右侧 AI 输入共用草稿，点击箭头进入助手继续编辑与发送。宽屏编辑区并列字段参考、配置和结果；可用宽度不足时先省去辅助字段栏，再堆叠配置与结果。已有结果明确标为已保存步骤的运行结果，仍保留失效、错误、来源与确认状态；不展示未实现的 Python / Pivot 等入口。
- Notebook 代码模式：文档操作栏提供“步骤 / 代码”切换并记住浏览器偏好，首次使用为步骤视图。步骤视图默认收起源内容；代码视图默认展开 SQL / 处理规则 / 配置，并把运行结果纵向排在下方。单元业务标题保持优先，代码可单独收起，结果仍然可见；代码区域独立横向滚动。SQL 编辑显示行号，处理规则支持表单 / JSON 切换和保存校验；代码视图不显示左侧字段参考栏，表单按 Notebook 容器宽度排列。
- Notebook 草稿：待采用区域可展开查看每个单元的新增、修改、移除和移动，修改对照包括代码及输入 / 连接等配置。保留整份草稿采用，手动编辑导致版本过期时明确提示并禁用采用；暂不采用不改变当前文档。
- Notebook 图表：默认预览序列使用炭黑到暖灰，网格接入统一细边框颜色；其他看板中用户显式指定的图表系列颜色继续保留。步骤视图的长配置在独立区域内滚动，代码视图纵向排列；较矮桌面窗口压缩起步区留白，保证工具栏可见。
- Notebook、Data Browser、导入、历史、API 设置、企业微信弹窗：统一表面、边框、按钮和字体；有数据的表格、编辑表单、选中态、结果预览与空白态使用同一色板。保留状态含义与原有功能。
- 语义模型：编辑、维度 / 指标、计算预览、保存与侧栏选中态统一黑白灰。原生 dialog 使用公共字体，底部操作区固定可见。
- 数据库字段目录：复用 Notebook 浅色表面，顶部显示表 / 字段数量与同步版本；搜索框占可用宽度，同步按钮在窄屏换行。数据库名与表名分行，字段表在自身区域横向滚动，截断和同步失败用明确文字提示。Dataset 来源采用可展开的步骤列表，定义与下载入口复用黑白灰按钮。2026-09-14 在 1440×1000、390×844 隔离 Edge 验证目录搜索 / 同步 / 查询表、实际保存与刷新后的来源展示 / 下载；手机先按正常交互收起已有 AI 侧栏，增加实际点击检查，四张最终截图已人工复核。证据位于 `site/.runtime/data-foundation-2026-09-14/`；源码与 3001 生效，3000 未发布。
- 数据源与 EDS：数据源详情仅保留“概览、字段、数据预览、数据配方”四个标签，移除详情中的“执行记录”入口、计数与内容页。字段类型、数据配方、原始工作簿、导入与结果卡片统一表面与边框；详情和帮助文字优先 11–12 px，说明自然换行。
- 数据源归档：本地项目成功后显示“数据表已移入回收站”，不再误称临时数据源删除；保存冲突、Notebook / 待确认预览引用或接口错误沿用详情错误区，失败不清除本地数据且可重试。2026-09-15 使用合成 CSV 验证归档、刷新恢复和错误重试，人工复核桌面与手机截图；布局、四个页签和原件保留规则不变。证据见 `.runtime/dataset-delete-2026-09-15/`，3001 已验收，3000 未发布。
- XLSX 导入：普通表格与 EDS 入口均不显示完整工作簿读取勾选项，导入后默认可按需分析完整原件。文件队列直接衔接操作按钮，不保留空白授权块；原始表格与助手使用“完整工作簿可用”等简洁说明。原件缺失时提示重新导入，不再提示勾选授权；文件会话和项目保留规则见架构文档。
- 看板编辑与历史：编辑器组件库、属性面板、选中框及变更预览使用灰度强调；定位文案为“边框标记区域”。历史详情字号提高，长记录自然换行，避免把预览强调色误当成成功状态。
- 可视化测试页：独立路由 `/visualization-lab` 的导航、选题、指令、预览标签和历史也使用同一色板；运行结果和人工评定保持明确的状态说明。
- 设备范围：当前仅维护电脑端，工作台最小宽度 1024 px；较小窗口保持桌面结构并允许横向滚动，不切换手机抽屉、单列导航或触屏专用控件。保留电脑窗口在 1200 / 1280 px 的密度调整、较矮窗口的留白调整和 Notebook 容器内重排。
- 动效：悬停反馈简短克制；尊重 `prefers-reduced-motion`。
- 可视化测试页 `/visualization-lab`：复用 `--studio-*` 色板，左侧选题与指令、右侧预览与检查，最小宽度 1024 px；单图预览填满可用区域，移除窄屏预览切换。图表系列保留模型生成的颜色，自动规则与人工评定分别展示，不以绿色状态代表视觉质量通过。
