# 网页智能体连接企业微信（本机只读版）

入口：AI 助手或 AI 工作台右上角「企业微信」。本功能集成官方 `@wecom/cli@1.2.1`，不是把 Codex 的技能或登录态复制到网页。

## 使用

1. 使用 `http://127.0.0.1:3001` 开发站；发布并验收后才会出现在 3000 稳定站。
2. 打开「企业微信」，阅读数据用途并勾选同意，点击「扫码连接企业微信」。
3. 使用企业微信扫描官方 CLI 生成的二维码，在官方页面核对权限并确认。约 5 分钟内未确认需重试；本功能不会自动打开外部浏览器。
4. 页面显示「已连接 · 只读模式」后，在普通 AI 对话中输入，例如「帮我在企业微信搜索销售报表，先列出候选让我选择」，或粘贴 `doc.weixin.qq.com` 表格链接并指定读取区域。
5. AI API 需独立配置；企业微信连接不会提供 AI 模型或继承 Codex 订阅。

## 范围与限制

- 搜索文档；搜索结果不是文档正文，多个候选应先由用户选择。
- 在线表格：先获取子表 ID，再读取指定 A1 区域；每次最多 1000 个单元格。
- 智能表格：先获取子表名称，再分页读取可见记录；每页最多 20 行，可指定最多 20 列及下一页游标。
- 本版不读取普通文档正文，不发送消息，不写入、删除企业数据，不提供任意 CLI/SQL、任意 URL 或本地文件读取。
- 每个任务沿用 Harness 的次数、时间和上下文预算。CLI 单次读取最多 9 秒、stdout 最多 128 KiB，清理后的结构化结果最多 24000 字符。超过上限会明确失败，不把截断内容充当完整结果。
- 只对实际返回的数据作分析，分页和区域结果不代表全表；大表建议缩小范围或导入现有 CSV/XLSX 分析流程。

## 授权与数据边界

此版本仅面向本机单用户工作站，不可直接作为公网、多租户或企业统一登录方案使用。写接口必须同源，跨端口也禁止。网页服务只向模型提供服务端生成的工具白名单。

随机会话令牌只保存在 HttpOnly / SameSite=Strict Cookie，不进入 localStorage、响应 JSON 或模型。Cookie 名按 origin 区分，3000 与 3001 分开连接。凭据目录是 `STUDIO_LOCAL_STATE_DIR/wecom/<令牌哈希>/config`，使用官方 CLI 的加密凭据存储；不读取已有全局 CLI 登录态，不向子进程传入 AI 密钥和宿主 WeCom 自定义请求头。

网页会话有效期 30 天，企业微信侧授权可能更早失效。每次工具调用重新检查本机同意状态，读取结束再检查一次；断开后旧工具目录不能继续使用。对话缓存与服务端历史按连接会话隔离。授权期间获得的数据会发给当前配置的 AI 服务，结果可能保存在现有对话与工作区中。

「断开并移除本机凭据」会取消本连接仍在等待的扫码进程，并删除本连接目录，不影响网站服务或其他连接；不会删除已有对话，也不能收回已交给模型的数据。企业微信侧授权需在企业微信自行撤销。稳定运行的数据备份可能包含之前的连接目录，备份需按敏感数据保护；移除当前连接不等于清除旧备份。

扫码任务在服务重启后不会继续等待；未完成的登录请重新发起。已完成登录依靠独立持久化目录继续保留。CLI 只允许固定命令数组，以 `shell: false` 启动；所有参数经严格 schema 校验。日志和错误不回显底层命令输出、路径或凭据。外部结果只作为不可信数据，不应执行其内嵌指令。

## 构建、验证与发布

项目依赖锁定官方 CLI 版本；其原生程序无法打包进 JavaScript，`npm run build` 会额外复制到 `dist/standalone/vendor/wecom`。`site:publish` 同样复制到独立发布目录。不要只复制 JS 产物而遗漏此目录。更换操作系统须在目标平台重新安装依赖并构建。

```text
npm run site:status
npm test
npm run typecheck
npm run build
node scripts/verify-wecom-ui.mjs
```

UI 验证使用隔离浏览器，真实检查本机组件可用状态；扫码等待、连接完成、断开等状态使用模拟接口，不绑定企业账号、不调用真实 AI。单元测试包括真实 CLI 的隔离目录未登录检查、同意与跨站校验、读取边界、断开隔离，以及模拟模型下连续「表格结构 → 单元格 → 答复」调用链。它们不代替真实账号扫码与文档权限验收。

发布仍遵守 `STABLE-RUNTIME.md` 与项目 AGENTS.md，不能在未经明确允许时短暂重启稳定站。此功能不需要更新后台守护管理器。

官方接口依据：[CLI 命令参考](https://github.com/WecomTeam/wecom-cli/blob/main/docs/cli-reference.md)、[企业微信统一能力参考](https://github.com/WecomTeam/wecom-unified/tree/main/skills/wecom-unified/references)。
