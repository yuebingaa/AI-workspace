AgentCanvas Portable for Windows x64
====================================

重要：请保持压缩包名称简短，并解压到较短的位置。推荐直接解压到 C:\，最终目录为 C:\AgentCanvas。不要在多层中文长目录中反复嵌套解压，否则旧版 Windows 资源管理器可能报告“错误 0x80010135：路径太长”。

使用方法
--------
1. 解压整个文件夹，不要单独移动其中的文件。
2. 双击 Start-AgentCanvas.cmd。
3. 等待浏览器自动打开。如果没有自动打开，请访问启动窗口显示的本机地址。
4. 在设置中的 AI 接口配置（或 AI 助手的 API 入口）输入自己的 DeepSeek API Key，验证并识别模型。
5. 在识别结果中选择要使用的模型，然后点击“应用模型”。
6. 使用完成后关闭启动窗口即可停止服务。

说明
----
- 目标电脑无需安装 Node、npm、pnpm、Python 或开发工具；已内置 DSH 和 Python 分析所需的无头浏览器。
- 本完整包每次启动默认使用 DSH；可在设置中切回原执行器，切换只保留到本次进程结束。
- DSH 使用网站受控数据分析工具，不能任意安装插件或执行系统命令。草稿仍需你确认采用。
- 本包未包含网站未开放的 DSH Office 转换 / 原生附件图片插件依赖；它不是通用全插件 DSH CLI 包，网站 Excel、Python、SQL 能力不靠这些插件执行。
- 网站和数据服务只监听 127.0.0.1，不会主动开放到局域网。
- API Key 只保存在本机服务进程内存中，不写入网页、工作区备份或本便携包。
- 关闭并重新启动后，需要重新输入 API Key。
- 本地上传数据及导出临时状态保存在 data/state 目录；迁移时可连同整个文件夹一起复制。
- AI 功能仍需要目标电脑能够访问对应的在线 API。
- 连接外部数据库仍需可访问的数据库和自己的只读凭据；本包不包含数据库服务或任何人的业务数据。
- 关闭窗口会结束正在执行的分析；请先保存项目并等任务结束。
- 本包未做代码签名；若安全软件阻止启动，请由你或公司 IT 核验来源和发布页 SHA-256，不要关闭安全软件。
- 当前便携版面向 64 位 Windows 10/11。

目录
----
app\       AgentCanvas 独立生产构建
runtime\   内置 Node.js 24 和 Notebook 无头浏览器
app\.runtime\dsh-bundled\  锁定版本的 DSH 完整依赖（请勿单独修改）
data\      首次运行时自动创建的本地状态目录
launcher.mjs  本地启动与浏览器打开程序
