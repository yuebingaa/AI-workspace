## 3. 当前 21 个工具

数量来自当前 `harnessToolNameSchema`。这是静态协议清单，不表示每轮会向模型开放全部工具。

| 工具组 | 工具名 | 数据子 Agent 可用 |
| --- | --- | --- |
| 基础读取 | `inspectDataset`、`inspectFields`、`querySemanticModel` | 是 |
| EDS 与工作簿读取 | `analyzeEdsReports`、`scanEdsRawWorkbook`、`queryEdsRawWorkbook`、`inspectEdsRawWorkbook`、`readEdsRawRows` | 是 |
| 分析与 Notebook | `createAnalysisPlan`、`createNotebookDraft`、`inspectConnectionSchema` | 否 |
| 数据处理 | `transformSpreadsheetData`、`previewDataRecipe`、`validateDataRecipe` | 否 |
| 导出 | `exportDataRecipeToExcel` | 否 |
| 页面与图表 | `inspectAppSpec`、`createEdsBreakdownChartPreview`、`createEdsLineIssueChartPreview`、`updateEdsTablePreview`、`createChangeSetPreview` | 否 |
| 外部能力 | `callMcpTool` | 否 |

`delegateDataTask` 是协调器单独向主模型开放的委派动作，不在上述业务工具枚举中；不能把它计成可由子 Agent 使用的第 22 个业务工具。

## 5. 后续改动从哪里进入

| 改动目标 | 首要接口 | 仍需处理 |
| --- | --- | --- |
| 新模型供应商 | `HarnessModel` + 服务端组装 | 协议、用量、上下文、图片和工具能力差异 |
| 新数据专家 | 角色注册、委派协议、协调器 | 白名单、上下文、共享预算、证据与任务验收 |
| 新数据库 | `ConnectionDriver` + `query.ts` | SQL 方言、权限、取消、精度与结果限制 |
| 新 Notebook 查询/日志实现 | `NotebookExecutionDependencies` | 结果表契约、血缘、超时与失败行为 |
| 新项目保存传输 | `ProjectStateWriter` | 修订、冲突和持久完成语义；存储格式变化另做迁移 |
| 新图表引擎 | 图表定义、绑定、组件注册与候选验证 | 目前不能只换一个适配器即完成全部迁移 |

新增角色不是只补一个名称。需要同时定义可执行能力、上下文范围、回传协议、预算与完成标准。
